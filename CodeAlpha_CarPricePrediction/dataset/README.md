# Dataset Instructions

Place the CarDekho dataset CSV (`car data.csv`) in this folder before running training or the notebook:

- **Source:** [Kaggle – Vehicle Dataset from CarDekho](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho)
- **Expected path:** `dataset/car data.csv`

*(CSV files in this directory are excluded from Git via `.gitignore`.)*
